Mode d’emploi

Dessiner

Choisissez un outil, puis dessinez sur les semaines. Les tracés restent accrochés aux dates quand vous défilez. Avec « Défiler », la molette ou le doigt font glisser le calendrier.

  • Libre : tracé à main levée.
  • Trait et Rectangle : tirez d’un point à l’autre.
  • Croix : un clic pose une croix.
  • Texte : cliquez pour écrire, Entrée valide, Échap annule. Cliquez sur un texte pour le modifier.
  • Déplacer : glissez un dessin ou un texte pour le déplacer. Pour un rectangle ou une ellipse, vous pouvez le saisir aussi à l’intérieur.
  • Gomme : touchez ou glissez sur un dessin pour le supprimer.

Redressage automatique

En tracé libre, gardez le stylo immobile un instant en fin de geste : une ligne, un rectangle, une ellipse ou une croix en un geste (forme de alpha) approximatifs se redressent.
