📋 Instances

Une instance est un calendrier partagé (ex : Équipe dev, Famille). Cochez/décochez une instance dans la sidebar pour l'afficher ou la masquer.

✏️ Saisir sa présence

  • Cliquez sur le rond coloré d'une instance dans la sidebar pour la désigner comme instance de saisie (bordure colorée).
  • Cliquez sur un jour du calendrier pour indiquer votre statut : Présent ou Peut-être.
  • Cliquez sur votre propre badge pour modifier ou effacer votre statut.

👤 Participants

Chaque participant a une couleur et une forme uniques visibles dans le panel sidebar et au survol des badges.

🔵 Badges sur les jours

  • Le fond coloré du badge = couleur de l'instance.
  • La forme colorée à l'intérieur = couleur + forme du participant.
  • Un ? indique "Peut-être".
  • Survolez un badge pour voir le nom du participant.
